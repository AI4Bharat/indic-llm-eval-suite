## Audit checklist

1. Answer contract: preserve short-answer requests for all solutions, functions, sets, intervals, tuples, parameterized expressions, extrema, counts, and transformed quantities. No assumed integer range, AIME-style answer, multiple-choice conversion, extra proof, or answer hint.
2. Logic: compare each quantifier's scope and dependency, all/any/some, existence/uniqueness, iff versus implication, negation, bounds, positive/nonnegative/nonzero, distinct/repeated, strict/weak, and minimum/maximum versus infimum/supremum. Natural prose order is acceptable only when semantics and protected-token order survive.
3. Algebra/number theory: preserve functional domains, coefficients, iteration/power notation, custom definitions, divisibility direction, quotient/remainder, parity, coprimality, base/digit rules, and endpoint/exception conditions.
4. Combinatorics/games: preserve ordered selections, multiplicities, colors/labels, adjacency, orientations, interval overlap, operation counts, player roles, first turn, update order, stopping condition, randomness, and possible versus guaranteed outcomes. Do not remove narrative as irrelevant.
5. Geometry: preserve line/ray/segment/extension, internal/external tangency, inside/on/outside, angle/vertex order, circle/center types, opposite edges, degeneracy constraints, locus conditions, and missing-diagram references.
6. Notation: all source digits, signs, labels, mathematical objects, code and math-mode LaTeX contents remain exact after JSON decoding, including math-mode prose. Standalone LaTeX wrappers/environments remain structurally identical; ordinary prose within non-math emphasis and list items should be translated. Preserve source malformed notation, line breaks, lists, and displays.
7. Indic language: requested language/script, professional local terminology, consistent custom terms, natural grammar, correct scope across postpositions/relative clauses, and unambiguous pronouns/roles. Preserve mathematical labels in Latin/Greek/source script and case. Do not introduce gender, honorific, number, or cultural assumptions. Conventional personal-name transliteration is acceptable; symbol transliteration is not.
8. Numerals/Unicode: only English/ASCII decimal digits `0123456789` (U+0030–U+0039) are allowed anywhere in the decoded problem, including prose, lists, labels, formulas, and LaTeX. Every Unicode decimal digit (category Nd) outside that set is a Critical error, even when its numerical value equals the source digit. This includes Indic, Arabic-Indic, extended Arabic-Indic, Ol Chiki, Meetei Mayek, and fullwidth digits. Compare the full ASCII digit sequence with English and separately check number boundaries, signs, leading zeros, separators, and decimal/base interpretation. A native digit escaped as JSON Unicode is still invalid after decoding. Flag lakh/crore regrouping, confusable symbols, lost diacritics, or bidi-induced changes. Preserve number-word values and units. RTL prose must leave formulas and ordered objects in source logical order. Meaningful joiners in ordinary prose are not errors merely for being non-ASCII.
9. Integrity: no solution/key leakage, unrequested assumptions, added glossary/lemma, source repair, schema drift, or lost constraints. Do not penalize faithful preservation of a source error or preferred but equivalent local terminology.

## Scoring: match the GSM8K/Math span-audit bands

- Critical: any non-ASCII decimal digit in the candidate problem, altered/added/omitted/reordered source digit, altered protected symbol/formula/math-mode LaTeX, damaged schema/line structure, changed required answer representation, or answer leakage. Native-script digits must never receive a passing score; report their exact spans and require restoration of the source ASCII spelling.
- Major: changed meaning, scope, domain, condition, role, mathematical term, source-error preservation, or materially wrong language/script.
- Minor: spelling, punctuation, or awkwardness with no meaning/notation/structure change.
- 90–100: professional quality, no Major/Critical errors; 100 only when no actionable issue exists.
- 70–89: only Minor errors.
- 40–69: at least one Major error, no Critical error.
- 0–39: any Critical error.
  Use the most severe error to constrain the score. A faithful source defect alone does not lower the translation score.
